# Extractores LCMV

Extensión de Chrome para trabajar directamente sobre la pestaña abierta.

Sitios compatibles:
- UNRAE
- VERcity
- BestSellingCarsBlog

## Instalación
1. Descarga y descomprime el ZIP del repositorio.
2. Abre `chrome://extensions`.
3. Activa **Developer mode**.
4. Pulsa **Load unpacked**.
5. Selecciona la carpeta `extractores-lcmv`.
6. Fija **Extractores LCMV** en la barra de Chrome.

Abre una página de ranking y pulsa **Extraer esta página**.
